# Frontend (React) for Expense Tracker

This is a minimal Vite + React demo UI that stores expenses in `localStorage` in the browser.

Run locally:
===================================================================
// in root terminal, run :
mvn spring-boot:run

// in seperate, root terminal, run :
cd frontend
npm run dev
===================================================================
ctrl+click the URL printed by `vite` (in the latter terminal) (usually `http://localhost:5173`).



Run Maven tests only:
===================================================================
// in root terminal, run :
mvn test
===================================================================

Notes:
- This web app utilizes Vite + React frontend, Spring Boot / Java backend, and Maven for JUnit testing.
